# LandedCost · 跨境落地成本计算器

跨境电商卖家/买家常用工具：计算商品到岸总成本（Landed Cost），
覆盖货值、国际运费、保险、关税、进口 VAT/GST 全链路。

## 功能

- 8 个目的国/地区规则（美/欧/英/日/澳/加/新/巴西），含各国 de minimis 免税门槛判断
- 6 大商品品类关税税率（服装/数码/美妆/家居/玩具/其他）
- 5 种物流渠道运费模型（EMS/DHL/FedEx/海运/专线），首重 + 续重计费
- 运输保险（货值 1.5%）可选
- 成本明细拆解 + 单件落地成本 + 税费占比
- 原生 Canvas 成本构成条形图，零依赖
- 3 种币种（USD/CNY/EUR）输入，自动换算

## 计算逻辑

```
CIF = 货值 + 运费 + 保险
关税 = CIF × 品类税率（货值低于目的国免税门槛时免征）
VAT/GST = (CIF + 关税) × 目的国税率
落地成本 = CIF + 关税 + VAT
```

## 运行

浏览器直接打开 `index.html`。

> ⚠️ 内置税率为演示用参考数据，实际业务请以各国海关与物流商最新报价为准。
